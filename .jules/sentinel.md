## 2024-05-21 - TextMeshPro Rich Text Injection
**Vulnerability:** A malicious client could send rich text tags (like `<color=red>`) in their `FixedString64Bytes` player name over a `ServerRpc`. TextMeshPro evaluates these tags indiscriminately, leading to UI spoofing or breaking layout for all clients when the lobby state is synced. This is the Unity equivalent of Cross-Site Scripting (XSS).
**Learning:** `FixedString` types in Unity Collections do not have built-in sanitization and are often blindly passed to UI elements.
**Prevention:** Always sanitize player-provided strings using a centralized utility (like `StringUtilities.SanitizeForRichText`) that strips `<` and `>` characters *before* updating authoritative network state via ServerRpc.
## 2024-05-22 - NGO RPC Information Exposure
**Vulnerability:** In Unity Netcode for GameObjects (NGO), using `[Rpc(SendTo.Everyone)]` combined with a client-side filter (e.g., `if (NetworkManager.LocalClientId != targetId) return;`) for sensitive data creates an Information Exposure vulnerability. The sensitive payload is transmitted to all connected clients over the network before the client-side check discards it, allowing a malicious client to intercept data intended for others.
**Learning:** Client-side filtering of network traffic is insufficient for security; the data must not be sent to unauthorized clients in the first place. `[Rpc(SendTo.SpecifiedInParams)]` causes compilation errors in this project's NGO version.
**Prevention:** For targeted delivery of sensitive information, always use `[ClientRpc]` and pass a `ClientRpcParams` object with `Send = new ClientRpcSendParams { TargetClientIds = new[] { targetId } }` to ensure the server only transmits the payload to the intended recipient.
