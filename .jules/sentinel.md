## 2024-05-21 - TextMeshPro Rich Text Injection
**Vulnerability:** A malicious client could send rich text tags (like `<color=red>`) in their `FixedString64Bytes` player name over a `ServerRpc`. TextMeshPro evaluates these tags indiscriminately, leading to UI spoofing or breaking layout for all clients when the lobby state is synced. This is the Unity equivalent of Cross-Site Scripting (XSS).
**Learning:** `FixedString` types in Unity Collections do not have built-in sanitization and are often blindly passed to UI elements.
**Prevention:** Always sanitize player-provided strings using a centralized utility (like `StringUtilities.SanitizeForRichText`) that strips `<` and `>` characters *before* updating authoritative network state via ServerRpc.
## $(date +%Y-%m-%d) - Information Exposure via Client-Side Filtering in Unity NGO
**Vulnerability:** The `NotifyDebugDataClientRpc` method used `[Rpc(SendTo.Everyone)]` to broadcast sensitive debug information to all connected clients, relying on a client-side `if (NetworkManager.LocalClientId != targetId)` check to filter the data. This means malicious clients could simply ignore the check and access debug data intended for other users, leading to Information Exposure.
**Learning:** In Unity Netcode for GameObjects (NGO), broadcasting data to everyone and filtering on the client is insecure for sensitive information. The payload is still transmitted over the network to all clients.
**Prevention:** For targeted delivery of sensitive information, always use `[ClientRpc]` and pass `ClientRpcParams` with `Send = new ClientRpcSendParams { TargetClientIds = new[] { targetId } }` to ensure the server only sends the data to the intended recipients.
