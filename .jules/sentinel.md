## 2024-05-21 - TextMeshPro Rich Text Injection
**Vulnerability:** A malicious client could send rich text tags (like `<color=red>`) in their `FixedString64Bytes` player name over a `ServerRpc`. TextMeshPro evaluates these tags indiscriminately, leading to UI spoofing or breaking layout for all clients when the lobby state is synced. This is the Unity equivalent of Cross-Site Scripting (XSS).
**Learning:** `FixedString` types in Unity Collections do not have built-in sanitization and are often blindly passed to UI elements.
**Prevention:** Always sanitize player-provided strings using a centralized utility (like `StringUtilities.SanitizeForRichText`) that strips `<` and `>` characters *before* updating authoritative network state via ServerRpc.
## 2024-05-19 - Insecure RPC Data Broadcast
**Vulnerability:** Found `[Rpc(SendTo.Everyone)]` used for debugging data broadcast (`NotifyDebugDataClientRpc`) in `AbilitySystemComponent.cs`. It doesn't correctly target the requesting client.
**Learning:** `[Rpc(SendTo.Everyone)]` paired with `if (NetworkManager.LocalClientId != targetId) return;` causes unnecessary network traffic for all clients, and exposes the data to all clients, which could be an information exposure if the data contains sensitive server state.
**Prevention:** For targeted data delivery in Unity Netcode for GameObjects (NGO), use `[ClientRpc]` or `[Rpc(SendTo.SpecifiedInParams)]` (if available, otherwise `[ClientRpc]`) combined with `ClientRpcParams { Send = new ClientRpcSendParams { TargetClientIds = new[] { targetId } } }`. Do not rely on client-side filtering for sensitive data delivery.
