## 2024-05-29 - Vector3.Cross Inherent Normalization in Unity Audio System
**Learning:** In Unity hot paths like `ExecuteOcclusionCheck` within `SoundOcclusion.cs`, calculating spread vectors involved multiple expensive `.normalized` calls (which use `Mathf.Sqrt()`). The cross product of two orthogonal, normalized vectors is inherently normalized. The original code did `Vector3.Cross(direction, Vector3.up).normalized * SpreadWidth` and then `Vector3.Cross(direction, right).normalized * SpreadWidth`. The second call was not only redundant (because it cross-producted an inherently normalized output of two normalized vectors) but also scaled the vector to `SpreadWidth` before re-normalizing it back to 1.0, and scaling it again.
**Action:** When generating orthogonal basis vectors via cross products in hot loops, apply `.normalized` only to the first cross product. Calculate the second basis vector using the normalized first one (`rightNorm`), which produces an inherently normalized result, and apply the scalar length (`SpreadWidth`) only at the end. This saves expensive squareroot calculations.
